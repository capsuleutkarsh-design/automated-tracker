Two engines, one app

Track in 2D. Solve in 3D.

Each pipeline has its own tab, its own settings and its own export set. Both read from the same media pool and write into the same scene folder.

2D Point Tracking · CoTracker3

Meta's CoTracker3 follows hundreds of points through a shot at once, with confidence and velocity filtering to throw out the ones that slip.

  • Three modes: automatic dense grid (up to 50×50), interactive point picker, and 4-point corner pin for screen replacements.
  • Offline or streaming model at 512p, 720p, 1080p or original resolution.
  • Tracking layers: multiple named, colour-coded layers, each solved and exported on its own.
  • Animated masks: keyframed inclusion and exclusion boxes and polygons keep the tracker off actors and moving objects.
  • Viewer tools: frame cache for instant scrubbing, sub-pixel loupe, matte and alpha views, motion-trail overlay, in/out range.

3D Camera Tracking · COLMAP

A full structure-from-motion solve that recovers the camera path, lens, and a sparse point cloud of the set, with an optional environment mesh.

  • Shot presets: handheld, walking, drone orbit, 360° VR, slow/subtle, fast action, and hierarchical multi-cluster for long shots.
  • Lens models: simple radial, radial, OpenCV, OpenCV fisheye, pinhole, spherical, EUCM, with optional distortion refinement.
  • Roto-aware: 2D masks are rasterised and passed to COLMAP so moving people never end up in the solve.
  • Batch solving: select several shots in the media pool, or none to solve everything.
  • Picks the best model COLMAP produced rather than assuming the first one, then meshes it if asked.

What it needs

Requirements

Everything is bundled: Python, PyTorch, COLMAP, FFmpeg and the CoTracker3 weights. Nothing is downloaded at run time.

OS

Windows 10 or 11, 64-bit. Installs to Program Files, so setup asks for admin once.

GPU

An NVIDIA GPU with CUDA makes both engines fast. Without one, tracking and solving fall back to the CPU.

VRAM

Automatic VRAM chunking sizes the tracking window to free memory and halves it on an out-of-memory error.

Disk

About 9 GB for the install. Frame caches and solves are written next to your footage.

Get it

Download and install

The installer is split into a small setup exe plus numbered .bin data files, because the bundled AI model and PyTorch runtime are larger than a single Windows installer can hold.

  1. Download every file from the latest release: the setup exe and each -1.bin, -2.bin, … file.
  2. Keep them in the same folder. The exe reads the .bin files beside it. If one is missing, setup stops and tells you which.
  3. Run the setup exe. Choose a location, optionally add a desktop shortcut and the sample clip.
  4. Launch Automated Tracker and drop a clip into the media pool.

Go to releases

Ship them together. The exe on its own installs nothing. Zip the whole set, or download all of them into one folder before running setup.

Running from source? Clone the repository and run SETUP.bat once. It pulls the same runtime from the release and unpacks it next to the code.

Built on

Open engines under the hood

CoTracker3

Meta AI's transformer point tracker drives the 2D tab. The bundled weights are released under the Creative Commons BY-NC 4.0 licence, which permits non-commercial use only.

COLMAP

The structure-from-motion and multi-view stereo pipeline behind the 3D solve, including its vocabulary tree for loop detection.

FFmpeg · PyTorch · Qt

Frame extraction, GPU inference and the interface. Blender, when installed, bakes Alembic and .blend exports.
